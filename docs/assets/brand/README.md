# agent-rules identity

The mark is a custom geometric **R**, built from three stacked rule lines. The cut through its center forms a command chevron, while the detached lower line recalls a terminal cursor. The open silhouette works without a surrounding app tile.

## Assets

- `mark.svg` / `mark.png`: primary evergreen and sage mark.
- `mark-dark.svg` / `mark-dark.png`: paper and sage mark for dark backgrounds.
- `mark-mono.svg` / `mark-mono.png`: single-color evergreen mark.
- `mark-dark-mono.svg` / `mark-dark-mono.png`: single-color paper mark.
- `wordmark.svg` / `wordmark.png`: horizontal logo for light backgrounds.
- `wordmark-dark.svg` / `wordmark-dark.png`: horizontal logo for dark backgrounds.
- `preview.png`: identity sheet with both backgrounds and small-size examples.
- `../favicon.svg`: the same mark, adapting to the browser's light or dark theme.

Icon PNGs are 512 × 512; wordmark PNGs are 1080 × 216. All PNG exports have transparent backgrounds. SVGs scale without loss. Wordmark SVG text uses system sans-serif fonts; use the PNG exports when exact text rendering matters.

## Use

The mark is checked at 16, 24, and 32 px. Prefer at least 24 px outside a favicon, and leave about one eighth of its width as clear space around it. Preserve the spacing between the lower line and the main shape. For single-color use, choose a monochrome asset rather than dropping the lower line.

The docs header uses the primary mark with native text. The README switches wordmarks to match light and dark themes.
